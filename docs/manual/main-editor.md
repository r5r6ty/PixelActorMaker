# 帧事件编辑器（sff/air/snd）

> 待补：界面截图。

## 三件套

| 文件 | 内容 | 格式 |
|---|---|---|
| `.sff` | 图集（base+法线）+ 精灵元数据 + 调色板 | JSON 文本 |
| `.air` | 动作（动画）与每帧**五类事件** | JSON 文本 |
| `.snd` | 音效（WAV 字节） | JSON 文本 |

三者同目录同名配套。数据结构见 [数据格式](../format/sff-air-snd.md)。

## 五类帧事件

每个动画帧可挂多类事件，事件对象用 `"type"` 字段区分类名：

| type | 含义 |
|---|---|
| `SpriteEvent` | 显示：引用图组/精灵 |
| `CollisionEvent` | 受击框（碰撞） |
| `BodyEvent` | 身体框 |
| `AttackEvent` | 攻击框 |
| `SoundEvent` | 音效触发 |

## 基本操作

- `Ctrl+S` 保存（无路径先弹另存为）；动作/组/音效名重名会在保存前拦截（名字是引擎侧字典键）。
- 组右键 / 双击 = 进入 gal 编辑器编辑该图组（多轨追加，不丢现场）。
- 导入入口在各行右键菜单：gal = 图组行；调色板 = 调色板行（`.pal` 单条 / `.gal` 取首帧色板，均可重导入）；声音 = 音效条。
- 撤销 `Ctrl+Z` / 重做 `Ctrl+Y`，历史面板可跳转。
- 预览泛光：工具栏「后处理」菜单（发光数据来自调色板每色「发光」通道）。
