# GIF 导出

- 入口：像素动画编辑器菜单「导出GIF…」→ 选路径 → 弹设置（缩放 1/2/3 + 透明色开关）→ 导出。
- 合成口径与预览一致：多轨按列表序叠加、隐藏帧成洞、**零延迟列跳过**。
- **透明色**（默认关）：只管**帧级透明色**——开=合成后再按帧透明色扣一遍（透明索引=帧透明色）；关=帧透明色当实色保留。层透明色键恒生效（合成语义，不受开关影响）。多轨画布尺寸不一时 letterbox 借空闲槽，仍按旧口径透明。
- 技术口径：8bpp 调色板直通、disposal=2、无限循环（NETSCAPE）；缩放为索引图最近邻。
- 无头导出：`PixelActorMaker.exe --gifexport <in.gal> <out.gif> [缩放] [参考轨gal...]`（CLI 恒为透明口径，不受 GUI 默认关影响）。

> 注意：导出目标帧必须是 8bpp 调色板帧（24bpp 直通色不支持 GIF 调色板导出，会明确报错拒绝）。
