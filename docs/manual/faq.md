# 常见问题

**Q：免费版和激活版差别？**
免费版可完整编辑与预览，点保存/导出会被拦下（弹「免费版限制」）。激活码放 exe 旁 `license.key` 重启即解锁。

**Q：支持 macOS / Linux？**
仅 Windows 10/11 x64。

**Q：产出的素材能商用吗？**
能。素材（gal/sff/air/GIF/PNG）完全归你，无任何限制；授权限制只针对编辑器软件本身。

**Q：软件放别人电脑上打不开/乱码？**
发布包必须**整体解压**（exe 旁的 dll 与 `gale_ops` 文件夹是运行必需），不要单拷 exe。

**Q：保存后想找回旧版本？**
保存自动写 `.bak` 备份（上一次的文件内容）。

**Q：界面语言？**
默认中文，`lang.txt` 写 `en` 切英文（需配套 lang 表随包）。韩文等其他语言：欢迎联系开发者。

**Q：Unity 里怎么读这些文件？**
见「数据格式」：`.sff/.air/.snd` 是普通 JSON（附 MugenSdk 纯数据类）；`.gal` 按容器格式规范解析（zlib 块 + 头 XML）。
