# 常见问题

**Q：免费版和激活版差别？**
免费版可完整编辑与预览，点保存/导出会被拦下（弹「免费版限制」）。激活码**绑定电脑**：菜单「帮助 → 关于」显示本机机器码，发给开发者换取激活码，在关于页粘贴即解锁。

**Q：支持 macOS / Linux？**
仅 Windows 10/11 x64。

**Q：产出的素材能商用吗？**
能。素材（gal/sff/air/GIF/PNG）完全归你，无任何限制；授权限制只针对编辑器软件本身。

**Q：软件放别人电脑上打不开/乱码？**
发布包必须**整体解压**（exe 旁的 dll 与 `gale_ops` 文件夹是运行必需），不要单拷 exe。

**Q：保存后想找回旧版本？**
保存自动写 `.bak` 备份（上一次的文件内容）。

**Q：界面语言？**
默认中文，支持 中文 / English / 한국어。切换：菜单 **帮助 → 首选项 → 系统 → 语言** 选择并按确定，重启程序生效（也可改 exe 旁 `config.json` 的 `"Language"`）。

**Q：动作/组列表里名字显示成 ??? ？**
文件里的动作名/组名是**创建者用它自己的界面语言**起的。编辑器按当前界面语言加载字体，不包含其他语言的文字，所以别的语言起的名字显示 `?`——**数据没有坏**（文件里存的是原文），把界面切回文件作者使用的语言即可正常显示。

**Q：能导入 MUGEN 的 .air / .sff 吗？**
不能。扩展名相同但格式不互通——本工具三件套是自有 JSON 格式，MUGEN 引擎读不了；反过来 MUGEN 的素材文件本工具也读不了。

**Q：Unity 里怎么读这些文件？**
见「数据格式」：`.sff/.air/.snd` 是普通 JSON（附 PAMSDK_Unity 纯数据类）；像素动画是 `.gal` 格式。
