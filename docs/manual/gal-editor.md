# 像素动画编辑器（gal）

> 待补：界面截图。本页先把结构与口径写全，截图后按图重排。

## 多轨时间轴

- 每条**轨道** = 一个独立可编辑的 `.gal` 文档（不是主/副轨关系，一视同仁）。
- 轨道行左缘 眼/锁 图标（会话级，不入 gal 文件）：眼=预览/导出整体跳过本轨（播放、悬浮预览、GIF 导出、A/D 步进同口径）；锁=本轨禁内容操作（不可选中/编辑帧，名字行菜单的回到起点/全部隐藏同步禁用；上下移/关闭等管理项保留），当前轨恒未锁。
- 轨道可横向拖动编排在时间轴不同位置（Offset 列偏移，可为负）；帧 f 位于列 f+Offset。
- 播放预览 / GIF 导出 = 按列把各轨的帧**叠加合成**（列表序 = 叠放序，底层先画）。
- `A`/`D` = 列步进（当前轨优先，从上到下找有帧的轨，环形）；`W`/`S` = 切图层；`Space` = 播放。
- 隐藏帧 = 该列成洞（不画不交互，列位置不变，每轨独立）；零延迟帧不占时间直接跳过。

## 帧与图层

- 帧：Shift 范围多选；双击 = 全选本轨相邻**同名**帧；帧属性弹窗（名称/延迟/透明色）编辑只入缓冲，应用 = 一个撤销步骤。
- 延迟三档显示：1/60 秒（默认）/ 1/100 秒 / 1/1000 秒；存储恒为毫秒。
- 图层：多选；格子左上角 眼睛/锁 图标；锁定层画笔类工具不生效。
- 特殊层（`del`/`Collider`/`Body`/`Attack`/`Center`）与特殊帧（名字含 `del`）：名字**红色标记**；特殊层不默认锁定——攻击/受击框可以直接画成特殊层导出，烘焙会过滤特殊层。

## 工具

| 工具 | 行为 |
|---|---|
| 铅笔 | 点/十字笔刷；**Shift+拖 = 拉直线**（按下起线、松手落线一个撤销步骤；拖动中 Shift 实时开关轴锁定） |
| 油漆桶 | 连通区填充 |
| 选色 | 当前层同色连通区=选区；Shift/Alt+点 = 泛洪加选/减选 |

- 没有橡皮：擦除 = 铅笔选透明索引（或透明绘制开关）。
- 选区：拉框 → 8 手柄缩放 → 移动浮层（松手不落地）；拖动按 Shift = 水平/垂直约束；复合选区 Shift 追加 / Alt 删减；旋转手柄（支点可拖、Shift=15° 吸附）。
- 剪贴板互通：复制 / 粘贴走系统剪贴板——选区像素可贴到画板、聊天窗口等外部软件，外部图像（截图等）也能贴进来；8bpp 帧粘贴时颜色自动归化为调色板最近色。

## 调色板

- 双击颜色格改色；颜色格**拖动**：无修饰=对调两色、Ctrl=覆盖、Shift=对调且像素索引跟着对调（全帧生效）。
- `SyncPal=1`（同步调色板）时显示/编辑统一使用第一帧的色板。
- 右键吸色（画布）按 Shift = 吸**合成显示色**（8bpp 按当前色板精确匹配索引）。
- 颜色深度：新建 `.gal` 默认 **8bpp（索引色）**；菜单「全部帧（当前轨道名）→ 颜色深度」可整体切换 8bpp ↔ 24bpp（全彩），全部帧×全部层一次转换 = 一个撤销步骤。
- 24bpp（非索引色）时调色板面板显示包内 `default.pal` 参考色板（只读点色，状态行显示当前 #RRGGBB）。

## 2D 参考

- 菜单「2D参考」（位于 3D参考 左边）→ 开启：右列出现参考面板，与 3D 参考同位——两者同开时 2D 在 3D 列左边，仅开 2D 时占 3D 的右端位。面板内：「打开图片…」（可多选）、「打开文件夹…」（目录内图片按名排序入列）；列表项右键「移除」，底部「清空」。
- 支持格式：png/jpg/jpeg/bmp/gif/tga/psd；gif 走自研解码器逐帧解析（disposal 合成、交错还原、0/1cs 延迟按 100ms 归一）。
- 控制项在面板上（3D 参考同款：控件在列表上面，悬浮窗只放画面）：GIF 二选一——「跟随帧」=按当前轨帧 0→当前帧延迟累计映射 GIF 时间轴循环，或「播放」=按帧延迟自由循环（速度可调）；「画布叠加」=洋葱皮式幽灵盖在画布上描图（底钉画布底/高 92%/水平居中，时间恒跟当前编辑帧），子开关「画布镜像」水平翻转叠加；「水平翻转」=翻转悬浮窗画面（2D 专属——3D 靠数字键转相机）。
- 悬浮窗：静态图直接显示，GIF 显示当前帧；适配居中，放大取整数倍保像素锐利。发布版包含本模块（界面多语言完整）。

## 撤销与保存

- 编辑器内撤销/重做（历史面板可跳转）；历史不跨「返回 ↔ 进入」保留。
- 保存 = 块级剪接写回（未改层逐字节保留）+ `.bak` 备份；「另存为」= 全部轨道另存（轨 0 用所选路径，其余加序号）。
