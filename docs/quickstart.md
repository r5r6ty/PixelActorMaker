# 快速上手

1. 解压发布包，双击 `PixelActorMaker.exe`（Windows 10/11 x64，免安装，**所有文件保持在一起**：exe 旁的几个 dll 与 `gale_ops` 文件夹是运行必需）。
2. 界面语言：默认中文，支持中文/English/한국어——菜单 **帮助 → 首选项 → 系统 → 语言** 选择并按确定，**重启程序后生效**（也可改 exe 旁 `config.json` 的 `"Language"`）。
3. 个性化自动记住：窗口位置/大小、gal 编辑器的工具/洋葱皮/预览缩放（exe 旁 `config.json`）、悬浮窗位置布局（`imgui.ini`），都是退出时自动保存，无需手动管理。
4. 两条制作路线：
   - **像素动画**：菜单「新建」或「打开」一个 `.gal` → 多轨时间轴逐帧绘制 → 「导出GIF…」看效果。
   - **角色三件套**：打开 `.sff`（配套 `.air`/`.snd` 同目录）→ 编辑动作与帧事件（攻击框/受击框/音效）→ Ctrl+S 保存。

## 免费版与激活

- 免费版可以**完整编辑**与预览；点保存 / 导出时提示「免费版限制」。
- 激活：把收到的激活码存为 exe 旁 `license.key`（纯文本一行），重启软件；菜单 **帮助 → 关于** 应显示「已激活：你的名字」。

## 数据在游戏引擎里使用

见「数据格式」：`.sff`/`.air`/`.snd` 是 JSON 文本（附 MugenSdk 纯数据类，可直接放进 Unity 工程）；像素动画为 GraphicsGale 兼容的 `.gal` 格式。
