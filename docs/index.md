# PixelActorMaker

像素角色动画与帧事件编辑器。面向独立游戏开发者的角色制作流水线工具：

- **像素动画编辑器**：图层 / 调色板（索引色）/ 多轨时间轴 / 选区浮层 / 洋葱皮 / 预览悬浮窗
- **帧事件编辑器**：攻击框 / 受击框 / 音效 / 显示等五类帧事件（JSON 数据，Unity 可直接解析）
- **GIF 导出**：8bpp 调色板直通，多轨叠加合成
- **数据格式开放**：`.gal` 容器格式与 `.sff`/`.air`/`.snd` JSON 格式全部公开（见「数据格式」），游戏引擎侧自行解析无门槛
