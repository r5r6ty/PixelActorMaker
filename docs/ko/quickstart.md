# 빠른 시작

1. 배포 패키지를 압축 해제하고 `PixelActorMaker.exe`를 더블클릭하세요(Windows 10/11 x64, 설치 불필요, **모든 파일을 함께 유지**: exe 옆의 dll 몇 개와 `gale_ops` 폴더는 실행에 필수).
2. 인터페이스 언어: 기본 중국어, 中文 / English / 한국어 지원 — 메뉴 **도움말 → 환경 설정 → 시스템 → 언어**에서 선택 후 확인, **프로그램 재시작 후 적용**(exe 옆 `config.json`의 `"Language"`로도 가능).
3. 개인 설정 자동 기억: 창 위치/크기, gal 편집기의 도구/어니언 스킨/미리보기 배율(exe 옆 `config.json`), 플로팅 창 위치 레이아웃(`imgui.ini`) — 종료 시 모두 자동 저장, 수동 관리 불필요.
4. 두 가지 제작 경로:
   - **픽셀 애니메이션**: 메뉴「새로 만들기」또는「열기」로 `.gal` 연 후 멀티 트랙 타임라인에서 프레임별 드로잉 →「GIF 내보내기…」로 결과 확인.
   - **캐릭터 3종 세트**: `.sff` 열기(같은 폴더에 `.air`/`.snd`) → 액션과 프레임 이벤트(공격 박스/피격 박스/효과음) 편집 → Ctrl+S 저장.

## 무료 버전과 활성화

- 무료 버전은 **편집 전체**와 미리보기 가능; 저장 / 내보내기 시「무료 버전 제한」안내 표시.
- 활성화: 메뉴 **도움말 → 정보** — 페이지에 표시된 **머신 코드**를 개발자에게 보내고, 받은 활성화 코드를 같은 페이지 입력란에 붙여넣고「활성화」를 누르면 잠금 해제(활성화 코드는 컴퓨터에 바인딩; 활성화 코드를 exe 옆 `license.key` 한 줄 텍스트로 저장하고 재시작하는 방법도 가능).

## 게임 엔진에서 데이터 사용

「데이터 포맷」 참고: `.sff`/`.air`/`.snd`는 JSON 텍스트(PAMSDK_Unity 순수 데이터 클래스 동봉, Unity 프로젝트에 바로 넣기 가능); 픽셀 애니메이션은 `.gal` 포맷.
