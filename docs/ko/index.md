# PixelActorMaker

픽셀 캐릭터 애니메이션 및 프레임 이벤트 편집기. 인디 게임 개발자를 위한 캐릭터 제작 파이프라인 도구:

- **픽셀 애니메이션 편집기**: 레이어 / 팔레트(인덱스 컬러) / 멀티 트랙 타임라인 / 선택 영역 플로팅 / 어니언 스킨 / 미리보기 창
- **프레임 이벤트 편집기**: 표시 / 피격 박스 / 바디 박스 / 공격 박스 / 효과음 5종 프레임 이벤트(JSON 데이터, Unity에서 바로 파싱 가능)
- **GIF 내보내기**: 8bpp 팔레트 직통, 멀티 트랙 합성
- **데이터 포맷 공개**: `.gal` 컨테이너 포맷과 `.sff`/`.air`/`.snd` JSON 포맷 전부 공개(「데이터 포맷」 참고) — 엔진 측에서 자체 파싱, 장벽 없음

## 다운로드

GitHub Releases 참고(무료 버전 바로 사용 가능; 편집은 전체 지원, **저장 / 내보내기는 활성화 코드 필요**).

## 라이선스

- 무료 버전: 전체 기능 편집 + 실시간 미리보기, 저장 / 내보내기 불가.
- 활성화 코드: **컴퓨터(머신 코드) 바인딩**. 메뉴 **도움말 → 정보**에 이 머신 코드가 표시됩니다 — 개발자에게 보내면 활성화 코드를 드리며, 정보 화면에 붙여넣으면 잠금 해제됩니다.
- 이 도구로 만든 소재(`.gal`/`.sff`/`.air`/GIF 등)는 전부 당신의 것이며 상업적 이용도 자유입니다.
