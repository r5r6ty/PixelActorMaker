# 픽셀 애니메이션 편집기 (gal)

> 보충 예정: 화면 스크린샷. 본 페이지는 먼저 구조와 기준을 정리했으며, 스크린샷 후 재편성 예정.

## 멀티 트랙 타임라인

- 각 **트랙** = 독립적으로 편집 가능한 `.gal` 문서(메인/서브 관계가 아니라 모두 동등).
- 트랙은 가로 드래그로 타임라인의 다른 위치로 배치 가능(Offset 열, 음수 가능); 프레임 f는 열 f+Offset에 위치.
- 재생 미리보기 / GIF 내보내기 = 열별로 각 트랙의 프레임을 **합성**(리스트 순서 = 쌓는 순서, 아래 레이어부터 그림).
- `A`/`D` = 열 이동(현재 트랙 우선, 위→아래로 프레임이 있는 트랙 탐색, 순환); `W`/`S` = 레이어 전환; `Space` = 재생.
- 숨김 프레임 = 해당 열에 구멍(그리지도 않고 상호작용도 없음, 열 위치 유지, 트랙별 독립); 지연 0 프레임은 시간을 소비하지 않고 바로 건너뜀.

## 프레임과 레이어

- 프레임: Shift 범위 다중 선택; 더블클릭 = 이 트랙의 인접한 **같은 이름** 프레임 전체 선택; 프레임 속성 대화상자(이름/지연/투명 색) 편집은 버퍼에만 반영, 적용 = 되돌리기 1회.
- 지연 3단 표시: 1/60초(기본) / 1/100초 / 1/1000초; 저장은 항상 밀리초.
- 레이어: 다중 선택; 셀 좌상단 눈/자물쇠 아이콘; 잠긴 레이어에는 브러시류 도구가 적용되지 않음.
- 특수 레이어(`del`/`Collider`/`Body`/`Attack`/`Center`)와 특수 프레임(이름에 `del` 포함): 이름 **빨간색 표시**; 특수 레이어는 기본 잠금 아님 — 공격/피격 박스를 특수 레이어로 그려 바로 내보내기 가능, 베이크 시 특수 레이어는 필터링됨.

## 도구

| 도구 | 동작 |
|---|---|
| 연필 | 점/십자 브러시; **Shift+드래그 = 직선 그리기**(누르면 시작, 떼면 확정 = 되돌리기 1회; 드래그 중 Shift로 축 고정 실시간 전환) |
| 채우기 | 연결 영역 채우기 |
| 색 선택 | 현재 레이어의 같은 색 연결 영역 = 선택 영역; Shift/Alt+클릭 = 플러드 추가/제외 |

- 지우개 없음: 지우기 = 연필로 투명 인덱스 선택(또는 투명 그리기 스위치).
- 선택 영역: 드래그 박스 → 8개 핸들 크기 조절 → 이동 플로팅(떼기 전까지 떨어지지 않음); 드래그 중 Shift = 수평/수직 고정; 복합 선택 영역 Shift 추가 / Alt 제외; 회전 핸들(피벗 드래그 가능, Shift=15° 스냅).
- 클립보드 연동: 복사 / 붙여넣기가 시스템 클립보드를 통해 처리 — 선택 픽셀을 그림판·채팅 창 등 외부 소프트웨어에 붙여넣기 가능, 외부 이미지(스크린샷 등)도 가져와 붙여넣기 가능; 8bpp 프레임 붙여넣기 시 색은 팔레트의 최근접 색으로 자동 규격화.

## 팔레트

- 색 격자 더블클릭으로 색 변경; 색 격자 **드래그**: 수식 없음=두 색 교환, Ctrl=덮어쓰기, Shift=교환하며 픽셀 인덱스도 함께 교환(전체 프레임 적용).
- `SyncPal=1`(동기 팔레트)이면 표시/편집 모두 첫 프레임의 팔레트 사용.
- 우클릭 색 흡수(캔버스) + Shift = **합성 표시 색** 흡수(8bpp는 현재 팔레트와 정확 매칭되는 인덱스).
- 색 심도: 새 `.gal`은 기본 **8bpp(인덱스 컬러)**; 메뉴「전체 프레임(현재 트랙명) → 색 심도」에서 8bpp ↔ 24bpp(트루컬러) 전체 전환 가능, 전체 프레임×전체 레이어를 한 번에 변환 = 되돌리기 1회.
- 24bpp(비인덱스) 프레임에서는 팔레트 패널에 패키지 내 `default.pal` 참조 팔레트 표시(읽기 전용 색 선택, 상태 줄에 현재 #RRGGBB 표시).

## 되돌리기와 저장

- 편집기 내 되돌리기/다시 실행(히스토리 패널에서 이동 가능); 히스토리는「돌아가기 ↔ 진입」간에는 유지되지 않음.
- 저장 = 블록 단위 스파이스 쓰기(변경 없는 레이어는 바이트 단위 보존) + `.bak` 백업;「다른 이름으로 저장」= 전체 트랙 저장(트랙 0은 선택 경로 사용, 나머지는 번호 추가).
