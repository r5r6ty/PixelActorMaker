# 프레임 이벤트 편집기 (sff/air/snd)

> 보충 예정: 화면 스크린샷.

## 3종 세트

| 파일 | 내용 | 포맷 |
|---|---|---|
| `.sff` | 아틀라스(base+노멀) + 스프라이트 메타데이터 + 팔레트 | JSON 텍스트 |
| `.air` | 액션(애니메이션)과 프레임별 **5종 이벤트** | JSON 텍스트 |
| `.snd` | 효과음(WAV 바이트) | JSON 텍스트 |

셋 모두 같은 폴더에 같은 이름으로 구성. 데이터 구조는 [데이터 포맷](../format/sff-air-snd.md) 참고.

**Unity 납품(`.json` 이중 확장자 형태)**: 다른 이름으로 저장/최초 저장 대화상자의「저장 형식」에서 **「JSON 캐릭터(Unity)」**를 선택하면 3종 세트가 `캐릭터.sff.json / 캐릭터.air.json / 캐릭터.snd.json`으로 저장 — Unity는 `.json`을 TextAsset으로 임포트해 바로 읽기 가능. 열기 대화상자와 커맨드라인 두 형태 모두 인식; 두 형태는 같은 논리 파일이며 언제든 상호 변환 가능(다른 이름으로 저장 시 다른 형식 선택).

## 5종 프레임 이벤트

각 애니메이션 프레임에 여러 이벤트를 달 수 있으며, 이벤트 객체는 `"type"` 필드로 클래스 구분:

| type | 의미 |
|---|---|
| `SpriteEvent` | 표시: 이미지 그룹/스프라이트 참조 |
| `CollisionEvent` | 피격 박스(충돌) |
| `BodyEvent` | 바디 박스 |
| `AttackEvent` | 공격 박스 |
| `SoundEvent` | 효과음 트리거 |

## 기본 조작

- `Ctrl+S` 저장(경로가 없으면 먼저 다른 이름으로 저장); 액션/그룹/효과음 이름 중복은 저장 전 차단(이름은 엔진 측 딕셔너리 키).
- 그룹 우클릭 / 더블클릭 = 해당 이미지 그룹 편집을 위해 gal 편집기로 진입(멀티 트랙 추가, 현장 유지).
- 임포트 진입점은 각 행 우클릭 메뉴: gal = 이미지 그룹 행; 팔레트 = 팔레트 행(`.pal` 단독 / `.gal`은 첫 프레임 팔레트 사용, 모두 재임포트 가능); 소리 = 효과음 항목.
- 되돌리기 `Ctrl+Z` / 다시 실행 `Ctrl+Y`, 히스토리 패널에서 이동 가능.
- 미리보기 블룸: 툴바「후처리」메뉴(발광 데이터는 팔레트 각 색의「발광」채널에서 옴).
