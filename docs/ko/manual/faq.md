# 자주 묻는 질문

**Q: 무료 버전과 활성화 버전의 차이?**
무료 버전은 편집과 미리보기 전체 가능, 저장/내보내기 클릭 시 차단됨(「무료 버전 제한」 팝업). 활성화 코드는 **컴퓨터 바인딩**: 메뉴「도움말 → 정보」에 이 머신 코드가 표시되며, 개발자에게 보내 활성화 코드를 받은 뒤 정보 화면에 붙여넣으면 잠금 해제.

**Q: macOS / Linux 지원?**
Windows 10/11 x64 전용.

**Q: 만든 소재를 상업적으로 사용할 수 있나요?**
가능합니다. 소재(gal/sff/air/GIF/PNG)는 전부 당신의 것이며 제한 없음; 라이선스 제한은 편집기 소프트웨어 자체에만 적용.

**Q: 다른 컴퓨터에서 실행이 안 되거나 글자가 깨져요?**
배포 패키지는 **통째로 압축 해제**해야 함(exe 옆의 dll과 `gale_ops` 폴더는 실행에 필수), exe만 단독 복사 금지.

**Q: 저장 후 이전 버전을 찾고 싶어요?**
저장 시 자동으로 `.bak` 백업을 기록(이전 저장분 파일 내용).

**Q: 인터페이스 언어?**
기본 중국어, 中文 / English / 한국어 지원. 전환: 메뉴 **도움말 → 환경 설정 → 시스템 → 언어**에서 선택 후 확인, 프로그램 재시작 후 적용(exe 옆 `config.json`의 `"Language"`로도 가능).

**Q: 액션/그룹 리스트의 이름이 ??? 로 표시돼요?**
파일의 액션명/그룹명은 **제작자가 자신의 인터페이스 언어**로 지은 것. 편집기는 현재 인터페이스 언어의 폰트를 로드하므로 다른 언어의 문자가 포함되지 않아, 다른 언어로 지은 이름은 `?`로 보임 — **데이터는 손상 없음**(파일에는 원문이 저장됨), 인터페이스를 파일 제작자의 언어로 되돌리면 정상 표시.

**Q: MUGEN의 .air / .sff를 임포트할 수 있나요?**
없습니다. 확장자는 같지만 포맷이 호환되지 않음 — 본 도구의 3종 세트는 자체 JSON 포맷이며, MUGEN 엔진은 읽을 수 없고 이 도구도 MUGEN 소재 파일을 읽을 수 없습니다.

**Q: Unity에서 이 파일들을 어떻게 읽나요?**
「데이터 포맷」 참고: `.sff/.air/.snd`는 일반 JSON(PAMSDK_Unity 순수 데이터 클래스 동봉); 픽셀 애니메이션은 `.gal` 포맷.
