# GIF 내보내기

- 진입: 픽셀 애니메이션 편집기 메뉴「GIF 내보내기…」→ 경로 선택 → 설정 대화상자(배율 1/2/3) → 내보내기.
- 합성 기준은 미리보기와 동일: 멀티 트랙을 리스트 순서로 겹침, 숨김 프레임은 구멍, **지연 0 열은 건너뜀**.
- 기술 기준: 8bpp 팔레트 직통, 투명 인덱스=프레임 투명 색, disposal=2, 무한 루프(NETSCAPE); 배율은 인덱스 이미지 최근접 이웃.
- 헤드리스 내보내기: `PixelActorMaker.exe --gifexport <in.gal> <out.gif> [배율] [참조 트랙 gal...]`.

> 주의: 내보낼 프레임은 반드시 8bpp 팔레트 프레임이어야 함(24bpp 트루컬러는 GIF 팔레트 내보내기를 지원하지 않아 명확한 오류로 거부).
