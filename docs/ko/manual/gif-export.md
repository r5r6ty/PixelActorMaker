# GIF 내보내기

- 진입: 픽셀 애니메이션 편집기 메뉴「GIF 내보내기…」→ 경로 선택 → 설정 대화상자(배율 1/2/3 + 투명 색 토글) → 내보내기.
- 합성 기준은 미리보기와 동일: 멀티 트랙을 리스트 순서로 겹침, 숨김 프레임은 구멍, **지연 0 열은 건너뜀**.
- **투명 색**(기본 끔): **프레임 수준 투명 색**만 제어 — 켬 = 합성 후 프레임 투명 색을 한 번 더 추출(투명 인덱스=프레임 투명 색); 끔 = 프레임 투명 색을 불투명 색으로 유지. 레이어 투명 키는 항상 적용(합성 시맨틱, 토글 영향 없음). 트랙별 캔버스 크기가 다르면 letterbox는 빈 슬롯을 빌려 기존대로 투명 유지.
- 기술 기준: 8bpp 팔레트 직통, disposal=2, 무한 루프(NETSCAPE); 배율은 인덱스 이미지 최근접 이웃.
- 헤드리스 내보내기: `PixelActorMaker.exe --gifexport <in.gal> <out.gif> [배율] [참조 트랙 gal...]`(CLI는 항상 투명 모드, GUI 기본값 영향 없음).

> 주의: 내보낼 프레임은 반드시 8bpp 팔레트 프레임이어야 함(24bpp 트루컬러는 GIF 팔레트 내보내기를 지원하지 않아 명확한 오류로 거부).
