# PixelActorMaker

Pixel character animation and frame-event editor. A character production pipeline tool for indie game developers:

- **Pixel animation editor**: layers / palette (indexed color) / multi-track timeline / floating selection / onion skin / preview window
- **Frame event editor**: five frame event types — display / hit box / body box / attack box / sound (JSON data, directly parseable by Unity)
- **GIF export**: direct 8bpp palette passthrough, multi-track composited rendering
- **Open data format**: the `.gal` container format and the `.sff`/`.air`/`.snd` JSON formats are fully public (see "Data Format") — parse them in your own engine, no barriers
